An end-to-end, modular **Retrieval-Augmented Generation (RAG)** pipeline designed specifically for Sanskrit literature, subhashitas, and classical narratives. The system is engineered to operate **fully on CPU-based inference** without requiring any GPU acceleration.

---

## 📌 Project Overview

This assignment requires building a production-grade Sanskrit RAG system capable of:
1. **Ingesting** Sanskrit documents in `.txt` or `.pdf` formats.
2. **Preprocessing & Indexing** text while respecting Sanskrit sentence/shloka terminators (*purna virama* `।`, `॥`).
3. **Accepting Dual Queries** in either canonical **Devanagari** or Romanized transliterations (**IAST, Harvard-Kyoto, ITRANS**).
4. **Hybrid Retrieval** pairing dense semantic embeddings (ChromaDB) with lexical keyword matching (BM25) and Sanskrit stem boosting.
5. **CPU-Only LLM Generation** leveraging quantized GGUF weights via `llama-cpp-python` and grounded context synthesis.

## 🔬 Core Innovations for Sanskrit Processing

### 1. Sanskrit-Aware Verse & Shloka Chunking (`code/ingestion.py`)
Standard character splitters arbitrarily cut Sanskrit shlokas and compound words (*Sandhi*). Our chunker segments documents along:
- Story and section headings
- Verse terminators (`॥` and `।`)
- Preserves a 100-character semantic overlap to maintain continuity across complex dialogues.

### 2. Dual-Script Query Parsing (`code/transliterate.py`)
Users can submit queries in Romanized phonetics (e.g., `shankhanaadaH` or `vṛddhāyāḥ`) or pure Devanagari (`शंखनादः`). The system automatically detects the input script scheme and normalizes it to Devanagari before executing retrieval.

### 3. Sanskrit Hybrid Ranking Formula (`code/retriever.py`)
To overcome Sanskrit morphological inflections (*Vibhaktis* and verb conjugations), we combine:
$$\text{Score}(d) = 0.50 \cdot \text{BM25}_{\text{norm}}(d) + 0.25 \cdot \text{Dense}(d) + 0.25 \cdot \text{StemBonus}(d)$$
Common Sanskrit stop particles (`किम्`, `इति`, `अथ`, `च`, `अपि`, `ततः`) are pruned to eliminate false positives.

## 🚀 Setup & Execution Guide

### 1. Clone & Set Up Environment
```bash
git clone https://github.com/sahil-karande/RAG_Sanskrit_Sahil_Karande.git
cd RAG_Sanskrit_Sahil_Karande

# (Optional) Create virtual environment
python -m venv venv
venv\Scripts\activate   # On Windows
```

### 2. Install Dependencies
```bash
pip install -r requirements.txt
```

### 3. Run Automated System Audit & Verification
```bash
python verify_setup.py
```

### 4. Run Benchmark Suite
```bash
python code/benchmark.py
```

### 5. Launch the Interactive Web Application
```bash
python -m streamlit run code/app.py
```
Open `http://localhost:8501` in your browser to interact with the Sanskrit RAG interface.
